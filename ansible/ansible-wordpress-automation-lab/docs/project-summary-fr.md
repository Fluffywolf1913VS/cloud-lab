# Résumé du projet Ansible

Ce projet documente un lab Ansible complet réalisé sur AWS EC2.

## Objectif

Automatiser la configuration de plusieurs serveurs Linux avec Ansible, puis structurer le code dans des rôles réutilisables.

## Réalisations principales

1. Mise en place d’un nœud de contrôle Ansible.
2. Connexion SSH vers plusieurs hôtes Linux.
3. Création d’inventaires INI et YAML.
4. Organisation des hôtes en groupes et groupes enfants.
5. Utilisation de `group_vars` et `host_vars`.
6. Exécution de commandes ad hoc.
7. Création de playbooks avec plusieurs plays.
8. Déploiement Apache et PostgreSQL.
9. Utilisation des facts, variables, conditions, boucles et tags.
10. Création de templates Jinja2.
11. Importation de playbooks.
12. Création d’un rôle WordPress structuré avec Ansible Galaxy.
13. Déploiement WordPress avec Nginx, MySQL et PHP-FPM.

## Résultat final

Le rôle WordPress permet de déployer automatiquement une stack web complète sur une instance Linux cible.

## Valeur portfolio

Ce projet montre une progression complète : des commandes ad hoc jusqu’à une automatisation structurée et réutilisable avec rôles. Il est adapté pour démontrer des compétences en Cloud, DevOps, Linux, cybersécurité opérationnelle et automatisation.
